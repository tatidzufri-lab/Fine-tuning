# Чат с моделью: inference/chat.py

Чат в терминале. Работает с базовой моделью отдельно или вместе с обученным LoRA-адаптером. Устройство (MPS, CUDA или CPU) скрипт выбирает сам.

## Как запустить

Только базовая модель, без дообучения:

```bash
python inference/chat.py \
  --base_model "Vikhrmodels/Vikhr-Llama-3.2-1B-Instruct"
```

С адаптером ретрита:

```bash
python inference/chat.py \
  --base_model "Vikhrmodels/Vikhr-Llama-3.2-1B-Instruct" \
  --lora_model "./fine_tuning/lora_retrit"
```

С адаптером и системным промптом:

```bash
python inference/chat.py \
  --base_model "Vikhrmodels/Vikhr-Llama-3.2-1B-Instruct" \
  --lora_model "./fine_tuning/lora_retrit" \
  --system_prompt "Ты помощник бренда ретрита «Познай себя». Пиши тепло, честно, без манипуляций." \
  --temperature 0.3
```

## Параметры

| Параметр | По умолчанию | Что задает |
|---|---|---|
| `--base_model` | обязательный | Имя базовой модели на Hugging Face |
| `--lora_model` | нет | Путь к папке с адаптером |
| `--system_prompt` | пусто | Системный промпт, роль модели |
| `--max_new_tokens` | `512` | Максимальная длина ответа в токенах |
| `--temperature` | `0.3` | Температура генерации |

Для Vikhr подходит температура 0,1–0,3: ответы точные и предсказуемые. На 0,5–0,7 формулировки разнообразнее. От 0,8 ответы становятся творческими, но менее стабильными.

## Команды в чате

| Команда | Что делает |
|---|---|
| `quit`, `exit`, `q` | Завершить сессию |
| `clear` | Очистить историю разговора |

Чат помнит последние 20 сообщений. Системный промпт при этом не теряется: если он задан, он остается первым сообщением истории.
